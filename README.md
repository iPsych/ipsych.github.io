# ipsych.github.io

Official academic website of June Christoph Kang, Research Professor in the Department of Brain and Cognitive Engineering at Korea University.

The site is a dependency-free static build intended for GitHub Pages. Open `index.html` directly or serve the directory with any static web server.

## Local preview

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Deployment

This repository is designed to be published as the `ipsych/ipsych.github.io` user site. Push the default branch to GitHub; GitHub Pages will serve it at <https://ipsych.github.io/>.
